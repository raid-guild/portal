# Venture Beyond Louchi display fonts

These Latin-subset webfonts are copied byte-for-byte from `raid-guild/brand` main commit `6e3ed06241e9b282bf24afff3dcfb525796a4ce4`. They derive from Archivo 2.001 by Omnibus-Type and are licensed under SIL Open Font License 1.1 (`OFL.txt`). The attached `SHA256SUMS` matches the source. For the complete variable fonts and other scripts, consult `typography/venture-beyond/dist/` in the brand repository.

The three files register six CSS faces: upright and italic in `Venture Beyond`, reverse slant in `Venture Beyond Retalic`, plus `Venture Beyond Extended` upright/italic and `Venture Beyond Retalic Extended` with width pinned to 125%. All support weight 100–900; the base families support width 62–125%.
