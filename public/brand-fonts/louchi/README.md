# Louchi display font provenance

The active Portal display faces are the canonical Venture Beyond Latin subsets from `raid-guild/brand` main `6e3ed06241e9b282bf24afff3dcfb525796a4ce4`. See [`venture-beyond/README.md`](venture-beyond/README.md) for the source, SIL Open Font License 1.1, and SHA-256 checksums.

The six Last Duel webfonts were removed from public assets after the brand audit identified them as Eurostile-derived private fonts. They are not registered or distributed by Portal. Older Grinder assets remain archived here; their embedded metadata was checked separately and did not identify Eurostile.
