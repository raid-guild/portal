# Ubuntu font provenance

Ubuntu variable normal/italic and Ubuntu Mono regular/bold files copied without
modification from raid-guild/brand at 0d80eb5 (`public/fonts`). The accompanying
`UbuntuMono-UFL.txt` is the upstream Ubuntu Font Licence 1.0, applicable to the
Ubuntu font software; it is retained alongside these files. These are local
site assets, loaded only when requested by a theme, not a reusable font package.
