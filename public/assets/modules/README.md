# Module artwork

`arcade-doorway.webp` is decorative AI-generated artwork for the Guild Cabinet's
Arcade entrance. It does not depict a playable module or live module activity.
Module cards continue to use their CMS thumbnails.

Generated with OpenAI ImageGen on 2026-09-09, then resized to 810 × 1080 and
encoded as WebP.

Prompt direction: portrait 3:4 pixel-art illustration of a warm amber dungeon
entrance, arched doorway in dark purple stone, candles, burgundy banners and a
small black cat. Dark plum edges that blend into the Arcade panel. Illustration
only, with no text, interface or logos.
