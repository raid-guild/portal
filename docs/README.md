# Portal Documentation

This directory captures planning notes and implementation checklists for evolving this
Payload boilerplate into a RaidGuild Portal.

The current direction is a CMS-backed discoverability hub:

- member profiles
- project visibility
- publishing workflows
- API access for approved consumers

The Portal should not try to replace Discord, host meetings, or become a project
management system. It should make people, projects, skills, roles, and published
updates easier to discover and connect.
